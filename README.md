## 🎮 About The Game
Coffin Clash is a fast-paced action game focusing on tight combat mechanics and engaging gameplay loops. Players battle through challenging scenarios with unique combat systems and animations.

## 🛠️ Tech Stack
- **C#**
- **Game Engine** (Unity / MonoGame)

## 🚀 Getting Started
1. Clone this repository: `git clone https://github.com/CadaKerem/Coffin-Clash.git`
2. Open the project in your IDE or Game Engine.
3. Build and Play!
